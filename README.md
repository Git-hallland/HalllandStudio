# Hallland Studio

> 스타크래프트 음악 맞히기 유즈맵을 누구나 쉽고 직관적으로 제작할 수 있는 통합 제작 도구

Hallland Studio는 복잡한 Excel, EPS 파일을 직접 수정하지 않고도
노래 등록부터 음원 처리, 게임 설정, 맵 빌드까지 하나의 프로그램에서 진행할 수 있도록 만든
Windows 데스크톱 애플리케이션입니다.

맵 제작 경험이 없는 사용자도 필요한 내용을 입력하고 설정하는 것만으로
음악 맞히기 맵을 제작할 수 있도록 직관적인 GUI 환경을 제공합니다.

---

## ✨ 주요 기능

- 🎵 노래 목록 등록 및 편집
- 🎤 제목 맞히기 / 제목 + 가수 맞히기 모드
- 📥 YouTube 음원 자동 다운로드
- 🔊 음원 정규화 및 OGG 자동 분할
- 🎬 오프닝 · 엔딩 음악 설정
- ⚙️ 게임 진행 및 맵 설정
- 💾 프로젝트 저장 및 불러오기
- 🗺️ EUDDraft 기반 One-Click 맵 빌드
- 🔄 GitHub Releases 기반 자동 업데이트
- 🐞 버그 제보 및 기능 피드백 요청

## 🚀 사용 방법

1. Hallland Studio를 실행합니다.
2. 새 프로젝트를 생성합니다.
3. 출제할 노래를 등록합니다.
4. 오프닝 · 엔딩 및 게임 설정을 입력합니다.
5. `MAKE MAP` 버튼을 누릅니다.
6. 생성된 `.scx` 맵 파일을 확인합니다.

## ⚠️ 주의사항

EPS 파일을 직접 수정하여 커스텀 기능을 사용하는 경우
업데이트 과정에서 사용자 수정 파일에 영향을 줄 수 있으므로 별도의 백업을 권장합니다.

사용자가 제작한 프로젝트 및 맵 데이터는 업데이트 대상에서 제외됩니다.
